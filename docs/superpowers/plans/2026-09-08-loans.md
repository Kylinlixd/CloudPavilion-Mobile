# 云阁借阅中心与加载状态 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 完善借阅、预约和成员借阅流程，并修复所有禁用按钮的永久转圈。

**Architecture:** 后端在现有 LoanService/ReservationViewSet 上扩展借阅参数与预约展示字段，保持现有路由兼容；移动端以独立 `loading` 属性区分操作中与不可用，并将借阅状态集中在 LoansScreen/BookDetailScreen 的局部状态中。

**Tech Stack:** Django REST Framework, React Native, Expo, TypeScript, Jest/React Native Testing Library.
