# 书籍详情信息与简介刮削设计

## 目标

优化云阁书籍详情页的信息层级：封面左侧、书名与作者及版权信息右侧，简介独立放在下方；当本地简介为空时，从可用的中文/国际图书元数据来源补全简介。

## 用户界面

- 详情页顶部保留返回藏书按钮，并与内容保持明确间距。
- 信息头使用响应式横向布局：iPhone 上封面约占可用宽度 42%，右侧信息占剩余空间；iPad 使用更紧凑的封面比例，避免标题区域过窄。
- 右侧依次展示书名、作者、出版社、出版日期、ISBN（有值才展示），版权/来源信息以低对比度辅助文字呈现。
- 简介放在封面与信息区下方，标题为“内容简介”；没有简介时显示明确的空状态文案。
- 借阅、实体副本、电子书和书摘模块保持现有顺序，不改变既有操作入口。

## 元数据流程

- 后端搜索接口继续以现有 provider 顺序工作，并为中文搜索结果补充详情页简介；解析失败时仍返回书目基本信息。
- 详情页打开后，如果书籍已有简介则直接展示；如果为空，调用现有元数据搜索接口，以书名查询并选取首个包含简介的结果。
- 成功刮削后将简介、封面、作者、出版社、出版日期、分类等空字段回写当前书目，避免每次打开重复请求；已有用户填写内容不被覆盖。
- 所有网络请求设置超时并允许失败，失败不会阻塞详情页，其余内容正常显示。

## 测试与验收

- 后端为中文 provider 详情解析和“仅补全空字段”增加单元测试。
- 移动端验证窄屏与 iPad 宽屏布局、长标题换行、无简介状态及网络失败状态。
- 运行后端相关测试、移动端 typecheck/lint/test，并使用 Release 构建在已连接 iPhone 真机启动验证。
