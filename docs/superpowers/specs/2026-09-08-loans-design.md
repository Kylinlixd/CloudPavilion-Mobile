# 云阁借阅中心与加载状态设计

## 目标

完善实体书借阅闭环，并修复禁用按钮误显示为永久加载的问题。用户可以在家庭范围内选择借阅人和归还日期，查看自己的借阅与预约，管理员可管理家庭成员的借阅。

## 范围

### 借出

- 书籍详情页点击“借出”打开底部弹窗。
- 默认借阅人为当前登录用户，默认归还日由家庭借阅策略计算。
- 成员选择器只展示当前家庭有效成员；归还日期必须满足后端策略约束。
- 提交期间只锁定当前副本，成功后刷新副本状态和借阅列表。

### 借阅中心

- 借阅页提供“借阅中 / 已结束 / 我的预约”筛选。
- 借阅卡展示封面、书名、借阅人、借出时间、应还日期、逾期状态和续借次数。
- 借阅人本人或家庭管理员可以归还；满足策略且未逾期时可以续借。
- 操作成功后局部刷新，失败显示后端业务原因并保留重试入口。

### 预约

- 不可借副本可发起预约，并显示当前预约/队列信息。
- 用户只能取消自己的待处理预约。
- 归还副本时后端按队列推进，并创建通知；移动端刷新预约状态。

### 加载状态

- `ActionButton` 使用独立的 `loading` 属性显示 `ActivityIndicator`。
- `disabled` 只表示不可点击，不再自动显示加载动画。
- 借阅、归还、续借、预约、上传和发布操作显式传递 `loading`，避免空表单按钮永久转圈。

## 后端接口与校验

- 扩展借出接口接收 `copy_id`、可选 `borrower_id`、可选 `due_at`。
- 服务层校验借阅人属于当前家庭且有效；非管理员不能替他人借阅。
- 归还日期不得超过家庭策略允许的借阅期限；仍执行最大在借数、并发锁和副本状态校验。
- 保留现有 `/loans/`, `/loans/checkout/`, `/loans/{id}/return/`, `/loans/{id}/renew/` 与 `/reservations/` 路由兼容性。
- 预约列表返回书名、封面、条码、队列位置和状态，便于移动端直接渲染。

## 错误与空状态

- 409 冲突显示后端返回的业务原因（副本已被借走、超过上限、重复预约等）。
- 网络错误显示“重试”，不清空当前页面数据。
- 借阅、预约均无数据时提供对应的引导操作。
- 逾期记录使用醒目状态，但不阻塞归还。

## 测试策略

- 后端：成员归属与角色权限、归还日校验、并发借出、预约取消、归还推进队列和通知。
- 移动端：禁用按钮不显示 spinner、显式 loading 显示 spinner、借出弹窗默认值与提交、归还/续借刷新、预约取消与筛选。
- 完成后运行后端测试、移动端单元测试、TypeScript 类型检查、ESLint，并在真机执行借出—归还—预约主流程。

## 非目标

- 本次不重做书架布局、不改变底部导航、不引入新的第三方借阅服务。
