# 藏书导入与选择模式设计

## 目标

将底部“工作台”更名为“首页”，把藏书添加入口收拢到右上角“导入”菜单，并提供接近微信读书的选择模式，支持全选和批量管理。

## 首页导航

- 底部四项固定为：首页、藏书、借阅、我的。
- 仅修改显示名称，不改变首页路由和已有数据加载逻辑。

## 藏书页

- 顶部标题区右侧放置“导入”和“选择”两个文字按钮。
- “导入”弹出操作面板，包含：扫码/拍照添加实体书、手动添加实体书、导入电子书（EPUB/PDF/TXT）。
- 移除页面主体中原有的两个独立导入按钮，避免重复入口。
- 保留搜索框和排序栏，六列封面网格继续使用虚拟化渲染。

## 选择模式

- 进入选择模式后，标题变为“选择书籍”。
- 左上角显示“全选/取消全选”，右上角显示“取消”。
- 每个书籍卡片显示选中勾选状态，点击卡片切换选中状态，不进入详情。
- 底部固定批量操作栏，包含：批量删除、批量标记已读/未读、批量归类、取消选择。
- 批量删除和归类仅调用已有后端能力；后端不支持的“已读/未读”状态，先以电子书阅读状态为目标并在无目标时给出提示。
- 删除前显示确认弹窗，操作成功后刷新书架并清空选择。

## 导入菜单交互

- 菜单采用底部 ActionSheet 或白色浮层，点击外部或取消按钮关闭。
- 三个选项分别导航至现有 AddBook 扫码/手动流程或触发现有电子书选择器。
- 菜单打开时不影响书架滚动位置。

## 验证

- 测试底部“首页”标签、导入菜单三项导航、选择/全选/取消状态和批量操作栏。
- 真机验证六列网格上选择多本书、批量删除确认、导入电子书和返回书架。
- 验证灵动岛下方安全区、底部操作栏不遮挡最后一行书籍。
