# 书架与我的页面设计

## 目标

让云阁在几十到上百本书时仍可快速浏览，并将通知从底部常驻入口整合到“我的”页面，同时保留借阅作为一级导航。

## 藏书页

- 顶部保留家庭名称、搜索和添加书籍入口。
- 增加排序栏：最近添加、最近阅读、书名、分类。
- 默认采用六列密集封面网格，封面比例统一，标题最多两行。
- 使用 FlatList 虚拟化渲染，避免一次性渲染上百张封面造成卡顿。
- 点击进入书籍详情；长按提供借出、编辑、删除、分享书摘操作。
- 无封面时显示统一云阁占位封面，不显示空白区域。

## 底部导航

固定为四项：工作台、藏书、借阅、我的。通知不再作为底部一级入口。

## 我的页面

- 顶部展示头像、实时用户名和当前家庭。
- 通知摘要卡展示未读数量及最近三条通知，点击进入完整通知列表。
- 家庭管理包含切换家庭、创建家庭、成员列表。
- 阅读数据包含年度借阅、当前阅读进度、书摘数量。
- 设置区域包含账号信息和退出登录。

## 数据与交互

- 藏书排序和搜索在客户端驱动请求参数，保持服务端分页/筛选能力。
- 通知摘要复用现有 notifications 接口，完整列表继续使用 NotificationsScreen。
- 所有页面保持安全区和灵动岛下方布局，底部内容预留导航栏高度。
- 网络失败时保留已有内容并显示可重试错误，不阻塞其他区块。

## 验证

- 移动端测试四项导航、六列网格、排序状态、我的页面通知摘要和空状态。
- 真机使用几十本模拟书验证滚动性能、点击详情和长按菜单。
- 验证未读通知数量、家庭切换、退出登录以及灵动岛下方的布局。
